# tabs-map-stats

Custom **tabs** block. Purpose: Region explorer: vertical tabs, each panel showing a map with numbered hotspot links, a stat grid, body copy and an arrow link.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: optional single-cell rows for intro heading or background image; then one row per tab: cell 1 = tab label, cell 2 = map image, bulleted list of hotspot links, stat paragraphs (bold value + caption), paragraph, arrow link.
