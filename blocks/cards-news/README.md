# cards-news

Custom **cards** block. Purpose: News listing with the first article featured large and the rest in a row of smaller cards.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per article: cell 1 = image, cell 2 = type label paragraph (e.g. Article) + title heading with link + optional excerpt + date paragraph.

## Supported variations

| Variation | Option class |
| --- | --- |
| Slider: equal-size cards in a horizontal scroller with prev/next arrows, no featured first card (Related Articles) | `slider` |
