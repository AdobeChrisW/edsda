# form

Custom **form** block. Purpose: Email newsletter signup form (email input + submit button).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: optional key/value rows: action (submit URL), label, placeholder, button, success, error; a single-cell row with a link also sets the submit URL. With no rows it renders an email field and a Sign up button.

## Supported variations

No variations.
