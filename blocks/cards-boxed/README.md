# cards-boxed

Custom **cards** block. Purpose: Translucent link boxes (icon, title, text, pill link) over a full-bleed background photo.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: optional first single-cell row = background image; then one row per box: cell 1 = icon image, cell 2 = h3 + text + link.

No variations.
