# carousel-split

Custom **carousel** block. Purpose: Auto-advancing slides with text left and image right, selected by labelled progress-bar tabs.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per slide: cell 1 = image, cell 2 = eyebrow paragraph + h2 + paragraph + CTA link; the h2 also labels the slide tab.

## Supported variations

No variations.
