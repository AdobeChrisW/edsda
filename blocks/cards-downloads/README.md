# cards-downloads

Custom **cards** block. Purpose: Grid of file downloads: thumbnail beside a title and a file-type/size download link.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per file: cell 1 = thumbnail, cell 2 = h3 title + link to the file (link text = file type and size).
