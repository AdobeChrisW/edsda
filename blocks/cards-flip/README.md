# cards-flip

Custom **cards** block. Purpose: Square photo cards with a name; a + button flips the card to show a bio.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card: cell 1 = photo, cell 2 = name heading + bio paragraph(s) shown on the back.
