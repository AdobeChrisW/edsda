# cards-video

Custom **cards** block. Purpose: Staggered 3-column grid of portrait video posters with play buttons that open the video in an overlay.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per story: cell 1 = poster image + link to the video (.mp4/Scene7), cell 2 = caption paragraph.
