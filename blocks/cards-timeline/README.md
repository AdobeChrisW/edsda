# cards-timeline

Custom **cards** block. Purpose: Horizontal year-by-year timeline slider over a background photo, active entry highlighted.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: optional first single-cell row = background image; then one row per entry, single cell: bold year/group label paragraph (optional) + milestone paragraph(s). Entries containing an image (sports club fixtures/leagues) render as centred logo cards; their link only shows on the active card. Default content placed before the block in the same section (eyebrow heading) is overlaid on the block photo.
